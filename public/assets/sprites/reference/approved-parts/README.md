# Approved reference parts

The author explicitly authorized extracting separate illustrations, icons and decorative details on 2026-10-03. Source JPEGs are immutable atlas inputs, not page backgrounds.

`manifest.json` identifies individual original graphics. `ReferencePart` displays them with native SVG viewports so no regeneration or interpolation changes source pixels. Runtime scaling is proportional. Source artwork retains its painted backdrop; these are not transparent cutouts.

The kit contains ten distinct class portraits, two Paladin illustrations, six monster portraits, six navigation icons, equipment and resource icons, two Paladin skill icons, a divider and texture swatches. Frames expose only corner/edge strips; their label-bearing centers are never displayed.

The sources contain only the supplied screenshots. Complete unobstructed landscape paintings and full-body illustrations for the other classes are absent. The obscured artwork cannot be reconstructed exactly.

Keep live labels, nicknames, amounts, multipliers, state and click targets in React. Do not render the full source atlas. All four original image hashes and declared crop bounds are checked by the asset test.
