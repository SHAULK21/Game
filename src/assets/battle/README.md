# Battle location artwork

Generated with the built-in image generation tool (not the API/CLI fallback). Final optimized assets are stored beside this file in `src/assets/battle/*.webp`, 1280 px wide. Each location has its own image; the combat component selects the dungeon or encounter region and prioritizes the arena.

## Shared prompt

Use case: stylized-concept. Asset type: production combat background for a mobile fantasy RPG. Generate ONE wide landscape illustration of this specific PLACE: [SCENE] Style: polished semi-cartoon fantasy game environment, sharp hand-painted textures, detailed tangible architecture and nature, coherent spatial perspective, crisp readable features, not flat shapes or abstract silhouettes. Ground-level eye-height view, wide 2:1 framing. Central fighting area has usable open space; scenery wraps around it. Moderate brightness so scenery remains recognizable behind UI. Fill the whole image. No characters, no monsters except any specifically mentioned tiny environmental bats, no UI, text, letters, logos, watermarks, collage, panels or borders.
