# Реальный уровень противника

Уровень, который показывается в бою, считается по **итоговым характеристикам** противника (после всех множителей игры:
элита, босс, угроза, баланс после 30 ур.) — а не берётся из данных. Код: `realLevel()` в `addons/aeth-addons.js`.

## Эталон
Герой уровня L с экипировкой по уровню (сила снаряжения растёт как g = 1 + L/25):
- HP = (160 + 48·L)·g, атака = (18 + 7·L)·g, защита = (6 + 3·L)·g.

Эталонный (обычный) монстр уровня L:
- выдерживает 4 удара такого героя: HP = 4 · атака героя;
- за удар снимает 12 % здоровья героя с учётом его защиты: атака = 0,12 · HP героя · (защита + 75) / 75;
- защита ≈ 2 + 2,2·L.

## Сила
`Сила = √(HP · (1 + защита/75) · атака)` — геометрическое среднее: живучесть и урон весят одинаково.

## Тип противника
| Тип | Множитель силы к эталону |
|---|---|
| Лёгкий (ур. 1–2) | ×0,85 |
| Обычный | ×1 |
| Элита | ×1,25 |
| Босс | ×1,6 |
| Страж вознесения | ×1,6 |

**Реальный уровень** = такой L, при котором `Сила эталона(L) × множитель типа = Сила противника` (двоичный поиск 1…400).

## Примеры (обычные монстры полей)
| Было в данных | Реальный |
|---|---|
| Свирепый лесной волк, 2 | 3 |
| Гоблин-разведчик, 4 | 5 |
| Клыкастый вепрь, 6 | 8 |
| Разбойник, 8 | 11 |
| Ядовитый тарантул, 12 | 13 |

## Стражи вознесения
С 15.11 Страж подстраивается под героя: HP ≥ max(2 × HP героя, 11 × атака героя), удар ≥ max(1,1 × атака, 16 % HP героя),
защита ≥ 35 % защиты героя (базовые цифры ранга — минимум). Подсказка «Подготовка: герой примерно N ур.» заменена на реальную силу
стража для текущего героя.
