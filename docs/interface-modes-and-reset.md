# Интерфейсы и сброс персонажа

При создании персонажа игрок выбирает «Современный» или «Фэнтези».
Переключатель также находится в шапке игры. Выбор сохраняется на устройстве.
При переключении остаются тот же персонаж, текущий бой, открытый раздел
и состояние открытия панели героя и админки. Навигация общая для обоих интерфейсов. Имя и класс при регистрации сохраняются между переключениями.

Фэнтези-экраны адаптированы из [PR #27](https://github.com/SHAULK21/Game/pull/27)
автора zhuravskayyar, версия `6af77f29ba7c6d6eeaf32361b073b20b8e04b1e9`.
Оформления разделены в `src/interfaces`, а правила, действия и состояние
остаются общими в `GameContext`. Спрайты и резервные изображения предметов
используются из текущего main. CSS фэнтези ограничен `data-interface="fantasy"`.
Кнопка начала охоты расположена перед бестиарием.

## Сброс через админку

Администратор ищет игрока по имени, username или Telegram ID, выбирает его
и подтверждает сброс. Проверка администратора выполняется сервером по
`ADMIN_TELEGRAM_ID` (либо `VITE_ADMIN_TELEGRAM_ID`).

В одной транзакции сбрасываются профиль, PvP, личные серверные предметы и
незавершённые операции наград. Активные лоты снимаются. Игрок выходит из клана;
если он глава, лидерство передаётся другому участнику. Клан единственного
участника удаляется с казной и складом. Telegram, Premium и история платежей
сохраняются. История телеметрии также сохраняется для анализа возвращаемости.
Ранее полученная выручка рынка повторно не начисляется новому персонажу.

Сервер увеличивает `players.reset_version`; операция записывается в
`admin_account_resets`. Повторная отправка того же ID не выполняет второй сброс.
Изменения схемы применяются обычным запуском сервера через `server/schema.sql`.

При входе клиент проверяет версию до загрузки сохранения. В открытой игре
проверка повторяется каждые 15 секунд и при возвращении в приложение.
Старое сохранение и ожидающие локальные операции удаляются; игрок снова
создаёт персонажа. POST-запросы устаревшей версии отклоняются сервером.
Если сервер недоступен, сохраняется существующее поведение локальной игры;
сброс применяется после восстановления соединения. Устройство полностью
офлайн нельзя очистить дистанционно.
