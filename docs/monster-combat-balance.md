# Баланс поведения монстров — 6 октября 2026

Эта запись относится к первой версии балансировки (`a9c594f`). Последующая настройка обычных целей и серий: [свободный выбор охоты](hunt-choice-balance.md). Для текущих уровней встреч и результатов серий используйте новый отчёт.

## Изменения

- У каждого из 31 шаблона монстров собственный ритм, зависящий от ID и скорости. Обычная атака, защита, суперудар и бросок склянки имеют разные диапазоны. Разброс внутри диапазона — 100–180 мс; автобой ускоряет задержки до 70%.
- Пример волка: обычная атака 603–710 мс, защита 805–915 мс, суперудар 1111–1215 мс. Это полное время действия, а не две складывающиеся задержки. Выбранный ход и его срок сохраняются при повторных рендерах; выход из боя отменяет ожидание.
- На 1-м уровне базовая вероятность выбора защиты — 4%, суперудара — 10%; плавно растёт до 22% и 40% к 61-му уровню. Это вероятность выбора, а не гарантированная частота: учитываются кулдаун, мана, уже активная защита и контроль.
- С 15-го уровня добавляются огненные/ядовитые склянки: 1 заряд до 40-го уровня, 2 до 75-го, затем 3. Вероятность выбора растёт от примерно 7% до 14%; кулдаун — 4 хода, периодический эффект — 2 хода. Брошенная или промахнувшаяся склянка расходует заряд.
- Защита больше не проигрывает постоянному выбору самой сильной атаки. Обычная стойка расходует ход без удара; авторский контрудар голема сохраняется. Защитный эффект накладывается и при уклонении героя.
- Пересчитаны рост урона, сила элиты/боссов и эффективность брони против высокоуровневых врагов. Враг сильнее героя более чем на 2 уровня получает дополнительную угрозу: +22% за каждый следующий уровень, максимум +140%.
- После 25-го раунда PvE-монстр усиливает атаки на 4% за раунд, максимум вдвое: это ограничивает затяжные циклы лечения/щита. Автобой учитывает уровни и склянки и не застревает в обычной защите при здоровье ниже 25%.
- Авторские ротации испытаний ранга и серверная модель PvP сохранены. Общие боевые изменения работают в обоих интерфейсах; визуальная тема fantasy не перерисовывалась. Подсказка доступного приёма больше не обещает гарантированный следующий ход.

## Методика

Настоящий GameProvider, воспроизводимый генератор LCG и ускоренные боевые таймеры. Десять классов, решения автобоя, без побега. Доступ к контенту открыт заранее; уровень героя фиксирован, опыт не повышает его во время проверки. Экипировка и расходники созданы из существующих рецептов; характеристики и таланты распределены между ветками, питомец — стартовый волк. Новая случайность действий и задержек меняет последовательность событий, поэтому старые и новые бои сравниваются по выборкам, а не попарно.

Профиль standard: четыре предмета обычного регионального крафта, rare, +5; без расходников. Prepared: четыре предмета элитного крафта, rare, +7, по два доступных зелья HP/MP. На первом уровне стартовые предметы. Это фиксированные контрольные сборки, а не идеальные билды и не процесс добычи экипировки. Открытие входа в подземелье не означает гарантированную победу на минимальном уровне.

Бои исполняют настоящую логику React GameProvider с настоящими статусами, навыками, сопротивлениями и решениями автобоя. Ускорены только ожидания. В сериях и подземельях здоровье, мана и ограниченные расходники переходят между боями; персонаж не создаётся заново в каждой комнате. Лечение от событий подземелья работает штатно.

## Повторение

```bash
npm test
npm run lint
npm run build
PVE_LEVELS=1 PVE_GEAR=starter PVE_MONSTER=m_bandit PVE_MODE=mod_standard PVE_RUNS=100 npm run balance:pve
PVE_LEVELS=1,5,8,12,25,40,55,75,90,100 PVE_MODE=mod_standard PVE_RUNS=3 npm run balance:pve
PVE_LEVELS=5,8,12,25,40,55,75,90,100 PVE_GEAR=prepared PVE_MODE=mod_standard PVE_RUNS=5 npm run balance:pve
PVE_LEVELS=8,25,55,100 PVE_GEAR=prepared PVE_RUNS=3 npm run balance:pve
PVE_LEVELS=1,8,25,55,100 PVE_GEAR=prepared PVE_MODE=mod_standard PVE_CHAIN=1 PVE_RUNS=3 npm run balance:pve
PVE_DUNGEONS=1 PVE_RUNS=3 npm run balance:pve
PVE_DUNGEONS=1 PVE_DUNGEON_LEVEL_BONUS=10 PVE_RUNS=3 npm run balance:pve
npm run balance:pvp
```

`PVE_OUTPUT` задаёт файл результата (по умолчанию `/tmp/pve-results.json`). `PVE_STRATEGY=attack` позволяет отдельно проверить простые атаки. Полный каталог задержек, агрегированные победы, здоровье, длительность и реальные действия монстров: [monster-ai-results.json](balance/monster-ai-results.json).
