# Региональная прокачка и проверка PvE

## Игровой цикл

1. В каждой зоне есть минимум два обычных противника, элита и босс. Шесть обычных побед открывают элиту; две победы над элитой открывают босса. Прогресс и причины блокировок показаны в охоте.
2. Базовое снаряжение создаётся из местной руды и материалов обычных врагов, без редкого катализатора или обязательного трофея босса. Качество не ниже необычного.
3. Элитные и мастерские региональные рецепты требуют соответствующей победы, гарантированных знаков элиты/печатей босса и местного катализатора. Их качество не ниже редкого; базовые характеристики выше на 12%/25%.
4. Победа над боссом открывает опасные режимы этой зоны. Обычный режим и Священный Свет доступны сразу; переходы между зонами сохраняют существующие требования уровня. Подземелья остаются отдельным доступным маршрутом. Победа над их региональным боссом засчитывается в прогресс.
5. Старые герои с минимум шестью общими убийствами сохраняют доступ к уже достигнутым по уровню зонам. Новые герои проходят этапы с нуля. Сохранения, уровни, таланты, предметы и ранги не сбрасываются.

Ранние серии сокращены: 2–3 врага до уровня 8, 2–5 до 25, далее 2–7. Элита и боссы идут одиночными боями. В обычных комнатах подземелий и дорожных засадах выбираются обычные враги. Выбранная сложность комнаты сохраняется после перезагрузки.

## Подготовка героя

- Заточка даёт прежние +6% за ступень, максимум +25. До +5 шанс 100%, до +10 — 75%, далее 45/30/20%. Ранние цены снижены; местный катализатор нужен после +10. Цена и защита неудачи видны до попытки.
- Первое вознесение D стоит 150 серебра без фрагментов: рекомендуются уровень 10 и заточка +3. Следующие ориентиры: C 25/+5, B 40/+5, A 55/+7, S 75/+8, SS 90/+10, SSS 100/+10. Это рекомендации, а не запрет ранней попытки. Стражи имеют фиксированные параметры, без подстройки под героя.
- Первая победа над региональным боссом гарантирует фрагмент. Повторные боссы дают его с шансом 40%, элита — 25%; бои вознесения не используются для фарма.
- Алхимия получает региональные настои здоровья и маны на уровнях героя 5–100 из обычных трофеев и местной руды. Рецепты учитывают уровень профессии и героя. Кузнечное мастерство сохраняет опыт и влияет на качество.
- Клановый рейд дополнительно пополняет казну серебром и рудой. Проект «Снабжение» усиливает их на 10% за ступень, до десяти ступеней. Личные амулеты масштабируются с уровнем клана. Клан не требуется для обычной охоты или вознесения.

## Бой

Авто-бой выбирает доступный выгодный навык, сохраняет ману при слабой цели, лечится при низком HP, использует защиту перед тяжёлым ударом и восстанавливает ману заклинателю. Учитываются настройки навыков, ультимативных приёмов и отступления. Лечение не выбирает зелья усиления и не расходуется при полном здоровье.

Святые/ядовитые приёмы физических классов теперь используют их атаку, сохраняя тип урона и сопротивление цели. Заклинатели используют магическую атаку для магических приёмов. Элита и боссы получают отдельные кривые HP, атаки и защиты. Каменный голем чередует укрепление и тяжёлый удар; после удара становится уязвимым на два хода.

## Проверка

Проверены 82 автоматических теста, TypeScript и производственная сборка. Новый интеграционный тест проходит настоящую цепочку 6 обычных → 2 элиты → босс, проверяет гарантированный первый фрагмент, элитный рецепт и сохранение прогресса. Для каждой зоны проверяется доступность материалов базовых рецептов без элиты и босса.

Выполнено 10 370 симуляций через настоящий `GameProvider`: 8 550 одиночных боёв основной матрицы, 800 боёв подготовленного раннего героя, 210 испытаний вознесения и 810 серий/одиночных проверок цепочек. Во всех наборах — ноль превышений лимита действий.

| Обычный режим, основной набор | Бои | Победы | Средние действия героя |
|---|---:|---:|---:|
| Обычные враги | 1 200 | 99,6% | 6,6 |
| Элита | 500 | 99,8% | 12,6 |
| Боссы | 900 | 93,1% | 23,4 |

Это средние по всем исходам, включая поражения. Начальные лёгкие противники могут умирать быстрее ориентира 6–12; сложность внутри зоны неодинакова.

Подготовленный профиль на уровнях 4/8/12 (элитный комплект +7, два зелья HP и два MP) выиграл все 250 боёв с боссами, в среднем за 21,1 действия. Вознесение на рекомендованных уровнях с базовым редким комплектом +5 и предыдущим заработанным рангом: 210/210 побед; средняя длительность D–SSS от 11,3 до 37,4 действия.

Опасные режимы рассчитаны на дополнительную подготовку: доля побед над боссами без зелий в базовом комплекте составляет 41,5% в густом тумане, 44,2% в кровавой луне и 7,7% в проклятии бездны. Это не обязательный путь открытия следующей зоны.

### Воспроизведение

```sh
npm test
npm run lint
npm run build
PVE_LEVELS=1,5,8,12,25,40,55,75,90,100 PVE_RUNS=5 npm run balance:pve
PVE_LEVELS=4,8,12 PVE_GEAR=prepared PVE_MODE=mod_standard PVE_RUNS=5 npm run balance:pve
PVE_LEVELS=10,25,40,55,75,90,100 PVE_ASCENSION=1 PVE_MODE=mod_standard PVE_RUNS=3 npm run balance:pve
PVE_LEVELS=1,4,8,40,100 PVE_CHAIN=1 PVE_MODE=mod_standard PVE_RUNS=3 npm run balance:pve
```

`PVE_OUTPUT` задаёт файл JSON, по умолчанию `/tmp/pve-results.json`. Дополнительные фильтры: `PVE_CLASS`, `PVE_MONSTER`, `PVE_MODE`; профили `PVE_GEAR=starter|basic|standard|prepared|strong`, переопределение `PVE_UPGRADE`.

Условия: десять классов, фиксированные случайные последовательности, сбалансированное распределение атрибутов и доступных талантов без специализации/мастерства, питомец-волк. Основной профиль — четыре редких предмета +5, без зелий; на уровне 1 — стартовое снаряжение. Региональные блокировки заранее открыты, чтобы изолировать баланс боя; сами блокировки проверяются отдельно интеграционным тестом. Таймеры ускорены, интервалы отключены. Применяется общий игровой алгоритм авто-боя с навыками и ультимативными приёмами, отступление отключено. Лимит — 150 действий героя, в серии 450. Это синтетические персонажи, не наблюдение за живыми игроками. Лесной босс проверен дополнительным набором 150 боёв после обнаружения отсутствующего босса зоны.

## Реальные данные

Кривая XP сохранена. Телеметрия боёв теперь различает класс героя и обычного врага/элиту/босса; прежние записи помечаются `unknown`. Доступны длительность, ходы, победы, XP, режим, зона; сессии показывают чистый доход с учётом расходов, отчёт — возвращаемость. Следующая настройка темпа должна опираться на эти реальные данные, особенно на провалы конкретных классов, доход за обычную сессию и возвращение на следующий день.
