# Иконки уникальных вещей (360 вещей, 24 комплекта)

Уникальные вещи делятся на 4 эпохи по уровням. Для каждой эпохи нужно 15 иконок (11 видов брони и украшений + 4 вида оружия) — всего **60 картинок**. Одна иконка используется всеми вещами этого вида в эпохе, редкость показывается цветной рамкой в игре.

**Общая часть** — добавлять к каждому промпту:

```
Fantasy RPG item icon, hand-painted dark fantasy game art, single object centered, 3/4 view, soft light from top left, rich detail, transparent background, no text, no frame, no ground shadow, 1024x1024
```

**Имена файлов:** `uniq-<вид>-<эпоха>.png`, например `uniq-helmet-1.png`, `uniq-bow-4.png`. Пришлите одним zip-архивом.
