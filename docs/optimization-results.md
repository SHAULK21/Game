# Оптимизация запросов, таймеров и fantasy-интерфейса

Исходная версия для сравнения: `4e05dd1c5a7fc9f9c6905bc6510b334de5145e55`. Приложенный аудит анализировал более ранний `e0771cdc`; изменения внесены поверх актуальных исправлений рынка и сохранений аккаунтов.

## Изменения

- Схема общего чата создаётся при запуске сервера из `schema.sql`. GET и POST чата больше не выполняют DDL.
- Аутентификация читает актуальную версию сброса аккаунта. Нового игрока создаёт один раз, Telegram-имя обновляет только при изменении. Обычное чтение API не обновляет `updated_at` и не влияет на порядок равных результатов рейтинга.
- Присутствие хранится отдельно в `last_seen_at`: heartbeat раз в минуту при видимом приложении, сервер не меняет строку повторно чаще минуты. Статистика кешируется на 15 секунд с объединением одновременных запросов. Старые игроки получают отметку присутствия при следующем heartbeat.
- Обе версии общего чата используют один hook: последние 80 сообщений при открытии, затем запрос новых сообщений по `afterId`, объединение по ID, отсутствие замены массива при пустом ответе. Автоматический запрос статистики выполняется раз в минуту. Курсор сдвигается только после опроса, поэтому отправка собственного сообщения не пропускает сообщения других игроков. Ручное обновление доступно.
- Снимок книги создаётся перед изменением раздела, а не по каждому клику. Несколько изменений навигации в одном обработчике используют один снимок. При `prefers-reduced-motion` снимок и перелистывание отключены. Измерения границ заголовка объединяются на кадр, одинаковое CSS-значение повторно не записывается.
- Три ресурса восстанавливаются одним таймером с временными метками и догоняют время после приостановки WebView. Полные ресурсы не создают новое состояние. Расход из полного запаса запускает новый период восстановления; старое время простоя не превращается в бесплатную энергию. Убрана случайная имитация числа игроков онлайн.
- Текстуры уменьшены до 512×512, WebP quality 80. Пергамент досье побайтово совпадал с основной текстурой и теперь использует общий URL. URL новых текстур содержит хеш содержимого.
- Production-файлы Vite с хешем и новые текстуры кешируются на год с `immutable`; HTML, включая fallback маршрутов, получает `no-store`. Старые текстуры оставлены для совместимости, текущие CSS их не запрашивают.

## Проверки

- `npm test`: 190 тестов, все прошли.
- `npm run lint`: TypeScript без ошибок.
- `npm run build`: production-сборка успешна. Предупреждение о большом чанке GameContext остаётся.
- PostgreSQL-совместимые проверки через PGlite: повторные auth-чтения, изменение имени, версия сброса, сохранение временной метки рейтинга, ограничение heartbeat.
- UI-проверки: все разделы в трёх интерфейсах, отсутствие снимков при обычном действии, снимок при переходе, отключение при уменьшенной анимации; курсор чата при отправке между опросами, дедупликация, частота статистики, отсутствие фоновых и перекрывающихся опросов.
- Существующие проверки рынка, восстановления квитанций, разделения аккаунтов и сброса прогресса проходят.

## Осталось для следующего этапа

Разделение большого GameContext, отложенные сохранения с немедленной записью квитанций, lease для очереди Telegram вместо отправки внутри транзакции, разделение CSS по интерфейсам. Они не реализованы этим изменением. Перед выбором конкретного устройства контекстов и загрузки стилей нужны React Profiler и Network; перед изменением очереди — измерения транзакций и задержки доставки.

FPS, API p50/p95 и время загрузки на телефоне не измерялись. Снижение размера текстур и успешные тесты не доказывают конкретный процент ускорения игры.
